## **Task List & Objectives**  

### **Task 1: Data Exploration and Summary**  
🔹 **Objective:** Understand and summarize key statistics in the dataset.  
🔹 **Steps:**  
✔ Import dataset into Power BI.  
✔ Perform exploratory data analysis (EDA).  
✔ Calculate key statistics (e.g., average age, investment percentages).  
✔ Visualize the summary statistics using charts.  

### **Task 2: Gender-Based Analysis**  
🔹 **Objective:** Analyze investment preferences based on gender.  
🔹 **Steps:**  
✔ Compare investment choices (equity, mutual funds, government bonds) by gender.  
✔ Create visual comparisons to highlight trends.  
✔ Derive key insights from the data.  

### **Task 3: Objective-Based Analysis**  
🔹 **Objective:** Explore the relationship between savings objectives and investment choices.  
🔹 **Steps:**  
✔ Analyze correlations between savings objectives (e.g., Capital Appreciation) and investment avenues.  
✔ Create visual representations of investment choices based on objectives.  

### **Task 4: Investment Duration and Frequency**  
🔹 **Objective:** Analyze investment durations and monitoring frequencies.  
🔹 **Steps:**  
✔ Visualize the distribution of investment durations.  
✔ Analyze how frequently investments are monitored.  
✔ Identify patterns affecting investment decisions.  

### **Task 5: Reasons for Investment**  
🔹 **Objective:** Identify and visualize key reasons for investment.  
🔹 **Steps:**  
✔ Perform trend analysis on reasons like better returns, tax benefits, etc.  
✔ Create charts showcasing frequently cited reasons for investment.  

### **Task 6: Source of Information**  
🔹 **Objective:** Analyze how investors gather financial information.  
🔹 **Steps:**  
✔ Identify common sources (Internet, newspapers, financial advisors).  
✔ Create visualizations showing the most used information sources.  

### **Task 7: Comprehensive Dashboard**  
🔹 **Objective:** Create an interactive Power BI dashboard summarizing all insights.  
🔹 **Steps:**  
✔ Design a user-friendly dashboard layout.  
✔ Integrate insights from all previous tasks.  
✔ Add interactive features for data exploration.  
✔ Ensure a professional appearance with polished visualizations.  

## **Key Insights from Analysis**  
📌 **Most investors prefer mutual funds over equity for long-term savings.**  
📌 **Retirement planning is the primary savings objective for most investors.**  
📌 **Mutual funds are the top investment choice for retirement plans.**  
📌 **Financial consultants are the most trusted source for investment advice.**
